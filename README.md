# GKI Kernel Build

GKI 内核编译仓库，支持 KernelSU/SukiSU/ReSukiSU + SUSFS。

## 支持的变体

- Official (KernelSU)
- SukiSU / SukiSU-Ultra (40726/40548)
- ReSukiSU / ReSukiSU(34943)

## 支持的内核版本

- 5.10 (Android 12)
- 5.15 (Android 13)
- 6.1 (Android 14)
- 6.6 (Android 15)
- 6.12 (Android 16)

## 触发编译

在 Actions 页面手动触发 `Android 内核构建-自定义` 工作流。

## 版本选择

查看 [VERSION_GUIDE.md](VERSION_GUIDE.md) 了解如何选择内核版本。
